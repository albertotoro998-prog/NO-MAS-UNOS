# No Más Unos

**Nunca más pierdas una nota por un simple olvido.**

Aplicación web para organizar tareas y entregas académicas y hacer seguimiento al rendimiento. Proyecto de SENA.

## Problema
Muchos estudiantes tienen bajo rendimiento por desorganización, y el celular suele ser su principal distractor.

## Solución
Una organización estructurada que convierte el celular en un asistente académico en tiempo real: calendario, tareas y seguimiento de notas en una sola interfaz.

## Misión
Facilitar la organización académica y el seguimiento del rendimiento.

## Tecnologías
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP, MySQL
- **Herramientas:** GitHub, Figma, Visual Studio Code
- **Metodología:** marco ágil Kanban
